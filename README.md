# PM Tool Project

Trois outils gratuits pour t'aider à prendre de meilleures décisions produit, de l'idée au prototype.

### 💡 [IdeaClassifier](idea-classifier.html)
Cette idée mérite-t-elle une phase de discovery, ou peut-elle aller direct en backlog ?

### 🔎 [DiscoveryAdvisor](discovery-advisor.html)
Quel artefact utiliser pour explorer un problème ou une solution (Opportunity Solution Tree, Story Map, JTBD...) ?

### 🧪 [ProtoAdvisor](proto-advisor.html)
Quel type de prototype construire pour valider une hypothèse, sans perdre de temps ?

## Comment l'utiliser

Aucune installation. Ouvre simplement [`index.html`](index.html) dans ton navigateur (double-clic sur le fichier) et laisse-toi guider.

Tes réponses restent dans ton navigateur — rien n'est envoyé ni stocké ailleurs.
